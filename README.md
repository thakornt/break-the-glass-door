# Break the Glass Door

เว็บจำลองการลากวัตถุในออฟฟิศไปชนประตูกระจก เพื่อหนีไฟที่ลามมาจากด้านหลังห้อง ผลการชนคำนวณจากกลศาสตร์การชน การดัดของแผ่นกระจก และกลศาสตร์รอยร้าว ไม่มีการกำหนดจำนวนครั้งที่ต้องตีไว้ล่วงหน้า

เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `src/core.js` | ตัวคำนวณการชน (impact solver): สัมผัสแบบ Hertz + การยุบตัวถาวร, แผ่นกระจกแบบโหมดแรก + impedance เฉพาะจุด, ความเค้นดัด (Roark), รอยร้าวรูปกรวย, แรงอัดผิวเทมเปอร์, กำลังแบบ Weibull |
| `src/objects.js` | ข้อมูลวัตถุ (มวล มวลที่มีผล ความแข็งโครงสร้าง กำลังยุบ) และขีดจำกัดของคน |
| `src/page.html` | หน้าเว็บ: ฉากด้านข้าง หน้ากระจก การลากวัตถุ ไฟไหม้ บันทึกการชน การทดสอบมาตรฐาน |
| `build.py` | รวมไฟล์ใน `src/` เป็น `index.html` |
| `test/calibration.js` | เทียบโมเดลกับ EN 12600, ECE R43 และวัตถุทุกชิ้น |
| `test/repeated-hits.js` | ดูการกระจายของจำนวนครั้งที่ตีจนแตก |

แก้ไฟล์ใน `src/` แล้วรัน

```bash
python3 build.py
node test/calibration.js
```

## การปรับเทียบ

- **EN 12600** (ตุ้มยาง 50 kg): เทมเปอร์ 10 มม. ไม่แตกถึงความสูง 1,200 มม.
- **ECE R43** (ลูกเหล็ก 227 g จาก 2 ม.): เทมเปอร์ 4–5 มม. ไม่แตก กระจกธรรมดาแตก

## ค่าที่เป็นสมมติฐาน

- ตัวคูณลดความเค้นของการชนที่สั้นกว่า 1 ms (ปรับให้ตรง ECE R43)
- รอยร้าวโตขึ้น 25% ของความลึกที่การตีครั้งนั้นสร้างได้ เมื่อตีจุดเดิมซ้ำ
- มวลที่มีผล ความแข็งโครงสร้าง และกำลังยุบของวัตถุเป็นค่าประมาณ ไม่ได้วัดจากของจริง
- คนออกแรงลากได้ 450 N ใส่พลังงานได้ไม่เกิน 150 J ความเร็วมือไม่เกิน 14 m/s

เป็นการจำลอง 2 มิติ ผลเป็นแนวโน้ม ไม่ใช่ค่าที่ใช้ตัดสินกรณีจริง
